## Description:
This submission includes the implementation of a multithreaded proxy server that supports HTTP requests and a custom HTTP client used to send requests through the proxy.

---

## Files Included:

1. **myproxy.cpp**  
   - Implements the proxy server.  
   - Features:
     - Parses command-line arguments for port, forbidden hosts file, and access log file.
     - Accepts and handles multiple client connections using threads.
     - Parses HTTP requests and headers.
     - Handles GET and HEAD methods.
     - Supports SSL/TLS connection to the destination server.
     - Logs requests with timestamps, method, hostname, status code, and bytes transferred.

2. **myclient.cpp**  
   - Implements the client that sends HTTP requests through the proxy.  
   - Features:
     - Accepts proxy IP, proxy port, and a destination URL (with optional port and path).
     - Constructs and sends HTTP GET, HEAD, or PUT requests.
     - Adds custom headers including Host, Connection, and X-UCSC-Student-ID.
     - Writes downloaded files to disk or prints headers to terminal.

3. **file.txt**  
   - A sample forbidden hosts file used by `myproxy`.  
   - Lists domains that the proxy should block with a 403 Forbidden response.

4. **log.txt**  
   - The access log file generated by `myproxy`.  
   - Contains one line per request, including timestamp, client IP, HTTP request line, response status code, and total bytes sent.

---

## Usage:
Note: Proxy must be running before running client
To run the proxy:
./myproxy -p 9090 -a file.txt -l log.txt
To run the client:
./myclient 127.0.0.1 9090 www.example.com:80/index.html
